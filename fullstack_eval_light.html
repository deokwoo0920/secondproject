평가 시나리오

여러분은 소규모 서점의 온라인 도서 관리 시스템을 만들어달라는 요청을 받았습니다.
수업에서 배운 Spring Boot REST API + React/Next.js 기술을 활용해, 도서 목록 조회와 새 도서 등록이 가능한 풀스택 애플리케이션을 완성하세요.

평가 진행 순서

  1. GitHub URL 제출 — 채팅 또는 제출창에 레포 주소 입력
  2. 로컬 실행 확인 — 백엔드 :8080 + 프론트 :3000 동시 구동
  3. 3분 시연 — 목록 조회 → 등록 → 상세 → 삭제 순 라이브 데모
  4. 질문 답변 — 구조 설명 1~2개 (암기 불필요, 이해 기반)
  5. 점수 공지 — 루브릭 기준 즉시 피드백

MethodEndpointStatus설명필수

GET/api/books/{id}200 / 404단건 조회 (ID 기반)필수
POST/api/books201 Created새 도서 등록 (@RequestBody)필수

Entity 필드 (Book.java)

Book.java
@Entity
public class Book {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;          // 자동 생성 PK

    private String title;      // 도서 제목 (NOT NULL)
    private String author;     // 저자명 (NOT NULL)
    private Integer price;     // 가격
    private Boolean available; // 대출 가능 여부 (default: true)
}
